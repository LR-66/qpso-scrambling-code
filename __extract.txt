[4] ABSTRACT
[5] In multi-user MIMO (multiple-in multiple-out) systems, to address the performance bottleneck caused by low interference coordination efficiency and poor scrambling code mapping adaptability, this paper proposes a scrambling code mapping optimization mechanism based on the improved QPSO (Quantum Particle Swarm Optimization) algorithm. Chaotic perturbation and adaptive control are used to enhance the global search capability, achieve dynamic matching and suppression of multi-user interference patterns, and improve the system’s anti-interference performance and communication stability. A scrambling code feature template is constructed from the interference covariance matrix, and Logistic chaotic perturbation is introduced during QPSO initialization to broaden the global exploration of the scrambling code distribution and to match the dynamic interference pattern with finer granularity. The fitness feedback adjusts the particle inertia weight online, steering the scrambling code update path along the interference variation trend, and a multi-round scrambling code remapping strategy reinforces the coordination between mapping stability and interference suppression. Experimental results show that the method still exhibits strong interference suppression capability in high-density user areas (900 users/km²), with an average ACPR (Adjacent Channel Power Ratio) of -30.7dB and an average SINR (Signal to Interference plus Noise Ratio) of 17.7dB. When the SNR (Signal-to-Noise Ratio) is 5dB, the BER (Bit Error Rate) and link interruption rate are 0.025 and 0.015 respectively, indicating high communication reliability and stability. The average number of convergence rounds is 14.6, and the average convergence time is 82.5ms. The optimization of the mapping mechanism has a fast convergence speed and strong adaptability.

[8] Introduction
[9] In multi-user MIMO communication systems, inter-user interference has become a key factor restricting system capacity and transmission reliability [1-2]. To improve spectrum efficiency and link stability, scrambling code mapping mechanisms are widely used in physical layer design to achieve interference separation and signal identification between users. Unlike beamforming and precoding, which primarily suppress interference at the signal level through spatial or angular domain processing, scrambling code mapping provides an additional degree of freedom in the code domain to separate users with overlapping spatial signatures, thereby complementing these physical-layer techniques in dense deployment scenarios [3-4]. However, traditional static or semi-adaptive scrambling code configurations are difficult to cope with complex interference patterns in dynamic channel environments, resulting in limited system performance [5-6]. Therefore, studying intelligent optimization algorithms with high convergence and strong global search capabilities to achieve efficient mapping in multi-dimensional scrambling code space has become an important breakthrough in improving interference coordination performance.
[10] The current scrambling code mapping mechanism in multi-user MIMO systems still faces multiple technical challenges in dealing with complex dynamic interference environments. The optimization process of the scrambling code sequence involves high-dimensional discrete space search. Traditional intelligent optimization algorithms are prone to slow convergence or fall into local optimality when dealing with such problems, affecting mapping efficiency and stability [7-8]. The user distribution, channel status, and interference intensity in the system have time-varying characteristics [9-10], making it difficult for fixed scrambling code configuration strategies to achieve precise matching of interference patterns, limiting the improvement of anti-interference capabilities [11-12]. Existing optimization methods lack sufficient diversity guidance in the particle initialization stage, resulting in limited search paths and difficulty in fully exploring the high-quality solution set in the scrambling code space [13-14]. At the same time, in the fitness evaluation process, most algorithms do not effectively integrate channel covariance information for feature modeling [15-16], weakening the correlation between scrambling code allocation and actual interference structure [17-18]. In the face of sudden interference changes or user access mutations, the existing mechanism has deficiencies in response speed and remapping efficiency, making it difficult to quickly adjust the scrambling code structure to maintain communication quality [19-20]. Overall, how to enhance the adaptability of scrambling code mapping to dynamic interference environments while ensuring efficient convergence of the algorithm is still a key link that needs to be broken through in current research. These issues are not only related to the stable improvement of system performance, but also directly affect the deployment feasibility and operation efficiency of future high-density wireless communication networks.
[11] This paper aims to propose a scrambling code mapping mechanism based on an improved QPSO algorithm to improve the dynamic adaptability and optimization efficiency of interference coordination in multi-user MIMO systems. The distribution diversity of particle initialization is enhanced by applying a chaotic perturbation strategy, which improves the global exploration ability of the algorithm in the high-dimensional scrambling code space. Combined with the adaptive weight adjustment mechanism, the optimization process can dynamically adjust the search direction according to real-time interference feedback and improve the response accuracy of the scrambling code configuration to channel changes. On this basis, a feature template model based on the interference covariance matrix is constructed to achieve effective matching between scrambling code allocation and interference structure, and a multi-round scrambling code remapping strategy is further designed to enhance the robustness and stability of the system under sudden interference or user state changes. The innovative fusion of Logistic chaotic mapping and the QPSO framework not only alleviates the premature convergence of traditional intelligent optimization methods, but also improves the balance between convergence speed and mapping quality. Under the premise of ensuring low computational complexity, this mechanism achieves more efficient interference suppression and more stable communication performance, providing a feasible physical layer optimization path for multi-user MIMO systems in future dense deployment scenarios. The simulation results characterize the performance of the proposed method in dynamic interference environments at both the analytical and the experimental level.
[12] The novelty of the proposed mechanism resides in the joint treatment of the code assignment structure, the initialization distribution, and the convergence control inside a single closed-loop formulation. The scrambling code mapping is cast as an assignment problem governed by the eigen-structure of the interference covariance matrix, which supplies the optimizer with an explicit analytical objective. The Logistic chaotic sequence is superimposed with the principal eigenvector of that covariance matrix during initialization, producing an initial particle distribution that is broadly diversified and simultaneously directed toward the dominant interference subspace, a guidance property absent from chaotic initialization schemes that spread particles uniformly over the search space. The contraction-expansion coefficient is adapted through the measured fitness fluctuation of the particle swarm, and the search path is periodically re-seeded by a multi-round remapping triggered by the deviation of the channel feedback, establishing a closed loop between the code allocation and the time-varying interference pattern.
[13] Related Work
[14] In recent years, many scholars have conducted in-depth research on the interference coordination problem in multi-user MIMO systems and proposed a variety of methods to optimize scrambling code mapping. Sumathi S proposed a low-complexity power allocation algorithm based on particle swarm optimization, which significantly improved spectrum efficiency and energy efficiency for user clustering and beamforming in broadband millimeter wave downlink non-orthogonal multiple access systems [21]. PSO (Particle Swarm Optimization) is widely used in scrambling code allocation problems due to its simple structure and easy implementation, but it is easy to fall into local optimality in high-dimensional space and its convergence speed is unstable [22-23]. To overcome these problems, subsequent studies apply classic intelligent optimization methods such as GA (Genetic Algorithm) [24-25] and SA (Simulated Annealing) [26-27], which use cross-mutation and probability jump mechanisms to enhance search diversity. Although these methods have improved the flexibility of scrambling code mapping to a certain extent, they still have problems of high computational complexity and low convergence efficiency in large-scale user scenarios. On this basis, the quantum behavior particle swarm optimization algorithm has gradually attracted attention due to its stronger global search ability. Its particle update mechanism based on the principle of quantum mechanics effectively avoids the phenomenon of premature convergence [28-29]. However, the traditional QPSO algorithm still lacks sufficient adaptability and rapid response ability when facing a dynamic interference environment, and especially in the initialization stage of the scrambling code distribution, it fails to fully consider the impact of chaotic characteristics on the search path [30-31]. In summary, the current mainstream optimization methods still have obvious limitations when dealing with complex interference problems in multi-user MIMO systems. There is an urgent need for a new scrambling code mapping strategy that integrates chaotic perturbations and adaptive control mechanisms to improve the dynamic coordination ability and anti-interference performance of the system.
[15] In response to the above problems, some studies have attempted to combine chaos theory with intelligent optimization algorithms to improve the global search performance of scrambling code mapping. Some scholars have proposed using Logistic chaotic mapping to initialize the particle swarm, making the initial solution distribution more diverse, thereby improving the algorithm’s ability to jump out of the local optimum [32-33]. Other studies have applied new technologies such as adaptive subarrays and dual intelligent reflectors to enhance the interference suppression and signal focusing capabilities of multi-user MIMO and improve spectrum efficiency and coverage [34-35]. Some work has combined the use of constrained waveform design and interference alignment technology to further enhance the matching degree between scrambling code allocation and interference environment [36-37]. Nevertheless, most of these methods are limited to the improvement of a single optimization mechanism and fail to form a complete scrambling code remapping closed-loop system. Especially in the face of sudden interference or sudden changes in user distribution, the existing mechanism is still difficult to achieve fast convergence and stable mapping. To this end, this paper proposes an improved QPSO algorithm that integrates chaotic perturbations, adaptive weight control, and multi-round scrambling code remapping strategies, aiming to improve the dynamic adaptability and global optimization ability of scrambling code mapping. Chaotic initialization and adaptive QPSO variants have been explored in prior optimization studies as independent operators, and their coupling with an interference-covariance-guided objective for scrambling code mapping in dynamic multi-user MIMO environments remains unaddressed. The present work takes up this position by expressing the aggregate interference power as an explicit function of the scrambling code mapping matrix and by driving the chaotic and adaptive search operators with the eigen-structure of that function. This method can not only effectively expand the search space in the initialization phase, but also dynamically adjust the optimization path according to system feedback, and finally achieve a high degree of coordination between scrambling code allocation and interference environment. Compared with traditional optimization methods, the proposed mechanism significantly improves the anti-interference performance and communication stability of the system in high-density multi-user scenarios while ensuring convergence speed.
[16] Methods
[17] This section elaborates on the proposed scrambling code mapping optimization mechanism, which consists of four main components: (1) construction of the interference distribution matrix and mapping table, (2) chaotic perturbation-based initialization using Logistic mapping, (3) adaptive inertia weight control for convergence speed adjustment, and (4) real-time reconstruction and feedback-driven remapping. The overall architecture is illustrated in Figure 1 and described in detail below.
[19] Figure 1. Scrambling code mapping optimization architecture for multi-user MIMO systems
[20] Figure 1 presents the scrambling code mapping optimization architecture for multi-user MIMO systems. The architecture comprises three stages connected in a directed flow, namely initialization, optimization iteration, and mapping feedback. The initialization stage reads the channel state information, accumulates the interference covariance matrix, and generates the Logistic chaotic perturbation sequence that spreads the initial particle positions over the scrambling code space. The optimization iteration stage evaluates the fitness of each particle from the accumulated interference covariance matrix, updates the contraction-expansion coefficient from the measured fitness fluctuation, and advances the particle positions until the convergence criterion is satisfied. A decision node then compares the deviation of the channel feedback with the preset threshold: an exceeded threshold routes the flow back to the optimization iteration with a relocated sub-swarm, and a satisfied threshold forwards the optimized position vector to the mapping feedback stage, where the scrambling code scheduling table of the current time slot is assembled and delivered to the physical layer.

[79] 3.4 Real-time Reconstruction and Feedback Adjustment of Interference Mapping Results
[80] According to the optimized particle optimal position results, the scrambling code allocation scheme for the current time slot is reconstructed. The system receiver evaluates the mapping strategy effect in real-time based on the channel quality feedback. If the deviation error exceeds the threshold, the particle group update process is restarted to enhance the scrambling code response capability.

A deviation below the threshold retains the existing scrambling code structure, so that the scheduling table is passed unchanged to the next time slot and unnecessary reconfiguration is suppressed.
[84] 3.4.1 Mapping Result Reconstruction Mechanism and Scrambling Code Configuration Update Strategy in Time Slot
[85] The interference structure fluctuates significantly in each communication cycle, and the scrambling code configuration needs to respond quickly to the interference changes in the current time slot. After the particle swarm iteration is completed, the scrambling code allocation scheme is immediately reconstructed according to the scrambling code vector encoded in the global optimal position. In this process, global unified allocation is not adopted, but the local mapping domain is divided according to the interference principal component clustering result, and each subdomain performs scrambling code configuration independently to improve the parallel mapping efficiency. The scrambling code assignment refers to the continuity weight of the scrambling code dimension in the particle position, and the scrambling code path of the particle near the optimal solution is converted into a position matrix, which is filled in the scrambling code resource scheduling table of the current time slot.
[86] The scrambling code weight penalty mechanism is applied in the mapping reconstruction process to prevent high interference areas from repeatedly occupying the same scrambling code resource. The resource scheduling table is expressed in matrix form. Each row corresponds to an interference cluster in the system; each column corresponds to a scrambling code index; the matrix element is the scrambling code allocation factor. After perturbation selection and boundary correction, the scrambling code candidate set is mapped to the matrix to form the scrambling code configuration result of this time slot. For the completed scrambling code allocation table, the corresponding interference overlap risk value is estimated in real-time to determine whether the allocation result meets the interference suppression requirements.
[87] This reconstruction method adopts a combined structure of partition mapping and disturbance compensation to avoid scrambling code offset in the edge area of the interference structure after the particle converges globally, especially in the multi-user critical state, to ensure that the edge users obtain a continuous and controllable scrambling code trajectory. After the update is completed, the configuration table is directly input into the channel end to drive the transmitter to perform the next time slot scheduling according to the new scrambling code scheme.

[109] Method Effect Evaluation
[110] This section presents comprehensive experimental evaluations of the proposed method. We first describe the simulation platform, channel models, antenna configurations, and parameter settings. Then we evaluate the effectiveness of threshold filtering and chaotic perturbation. Subsequently, we compare the proposed method with state-of-the-art optimization techniques in terms of interference suppression, communication reliability, convergence speed, and computational resource consumption.
[111] 4.1 Experimental Data and Settings
[112] In the experimental evaluation part, a simulation platform for a multi-user MIMO system is constructed using MATLAB R2022a to verify the performance of the improved QPSO scrambling code mapping mechanism. The antenna configuration adopts 64 transmit antennas at the base station (uniform planar array, UPA) and 4 receive antennas per user. The channel model follows the 3GPP TR 38.901 Urban Micro (UMi) scenario, incorporating Rayleigh fading with spatial correlation, large-scale path loss (path loss exponent of 3.5), and a time-correlated Gauss-Markov process to capture fast fading dynamics. The modulation scheme is QPSK with a subcarrier spacing of 15 kHz and a system bandwidth of 20 MHz. The traffic model assumes a full-buffer condition to fully excite multi-user interference coupling. The SNR ranges from 5 dB to 30 dB with a step of 5 dB. All simulation results are averaged over 500 independent channel realizations to ensure statistical confidence. The experimental data covers different user densities (from 100 users/km² to 900 users/km²) to test the adaptability of the algorithm in a dynamic interference environment. A unified interference model and consistent channel variation conditions are applied to all compared algorithms to ensure fair evaluation. During the experiment, the interference covariance matrix is constructed by capturing the channel state information between the transmitter and the receiver in real-time as the input for the scrambling code mapping optimization. The interference matrix is symmetric and threshold filtered to highlight the main interference path and reduce the impact of noise. The simulation platform uses a sliding window statistical strategy to update the interference matrix to ensure its timing stability and dynamic adaptability. In addition, to evaluate the communication reliability, the system tests the bit error rate and link interruption rate under different signal-to-noise ratio conditions (5dB to 30dB) and collects data through multiple independent experiments to ensure the statistical representativeness and reproducibility of the results. The experimental setting also covers the test of convergence speed and resource consumption.

[116] 4.2 Effect of Threshold Filtering Processing
[117] The interference intensity matrix result is constructed by collecting the channel state information of all transmitting and receiving antennas in the system. The undesired signal power between each pair of transmitting and receiving ends is calculated and converted into an interference intensity index to form the original interference matrix. The matrix is symmetric to ensure the bidirectional consistency of physical interference. The median is chosen because it inherently represents the central tendency of the interference intensity distribution, ensuring that approximately half of the weaker interference links are filtered while the dominant interference paths are preserved. This process effectively removes noise and invalid interference connections and highlights the main interference paths. The data generation adopts the sliding window accumulation method to ensure the timing stability and dynamic adaptability of the matrix. The obtained matrix not only reflects the spatial coupling characteristics of the actual system, but also provides precise input data for the subsequent scrambling code mapping optimization.

[154] Conclusions
[155] This study proposes an improved quantum particle swarm optimization (QPSO) algorithm that integrates chaotic perturbation and adaptive weight control for scrambling code mapping optimization in multi-user MIMO systems. This mechanism strengthens the diversity of the scrambling code initialization and adjusts the search path adaptively, enhancing the global search capability and the convergence speed of the algorithm. The mapping strategy achieves a high degree of matching between scrambling codes and interference patterns by constructing the interference covariance matrix feature template, significantly improving the system’s anti-interference ability and communication stability. The improved algorithm has an average ACPR of -30.7dB in high-density user areas (900 users/km²) and an average SINR of 17.7dB; when the SNR is 5dB, the BER and link interruption rate are 0.025 and 0.015, respectively. It shows stronger interference suppression effect and better communication reliability in dynamic interference and user-dense scenarios, and has low computing resource consumption and fast convergence characteristics, meeting the real-time and efficiency requirements of practical engineering applications. The proposed scrambling code mapping mechanism provides a practical solution for interference coordination of multi-user MIMO systems and supports the performance improvement of high-density wireless communication networks. The evaluation is conducted on a simulation platform under the assumptions of a single cell, perfect channel state information at the transmitter, and full-buffer traffic, and the reported gains remain specific to the urban micro configuration of Section 4.1. Extension to multi-cell deployments with imperfect channel state information and bursty traffic constitutes the next step of this line of research.
